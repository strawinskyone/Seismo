КЛЮЧЕВЫЕ ИЗМЕНЕНИЯ v9.4.0:
1. Новая архитектура DAQ:
   - DataAcquisitionProcess(multiprocessing.Process) в acquisition_process.py.
   - DAQ и GUI работают в разных процессах → разные GIL → нет contention.
   - Данные передаются через multiprocessing.Queue (maxsize=50).

2. main.py:
   - Убран DataAcquisitionThread (QThread).
   - Добавлен poll timer (50 мс) для чтения из mp.Queue.
   - closeEvent: корректная остановка DAQ процесса (join → terminate).

3. config.py:
   - VERSION = "v9.4.0".
   - Добавлен DAQ_QUEUE_MAXSIZE = 50.
   - Исправлен баг: S_SEARCH_POST_P_END_SEC = 0.5 восстановлен.

4. Ожидаемый результат:
   - Потери данных < 5% (цель < 1-2%).
   - Пилообразный тренд потерь исчезает.
   - Стабильная работа часами без деградации.
